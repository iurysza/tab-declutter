# Publish Tab Declutter to the Chrome Web Store

Status: v0.1.1 is published. v0.2.0 is ready to upload as an update.

This checklist follows the current [Chrome Web Store publishing documentation](https://developer.chrome.com/docs/webstore/publish).

## 1. Publisher account

The publisher account is set up and verified. Re-authenticate in the [Chrome Developer Dashboard](https://chrome.google.com/webstore/devconsole) if it asks.

## 2. Build the upload package

Run the full gate before packaging:

```sh
bun install --frozen-lockfile
bun run check
rm -f tab-declutter-v0.2.0.zip
(cd dist && zip -qr ../tab-declutter-v0.2.0.zip .)
unzip -l tab-declutter-v0.2.0.zip | sed -n '1,40p'
```

`manifest.json` must be at the ZIP root. Do not upload a ZIP that contains a top-level `dist/` directory.

Check the built manifest before every submission:

```sh
jq '{name, version, description, permissions, optional_host_permissions, commands}' dist/manifest.json
```

Every update must increase the manifest version.

## 3. Prepare the listing

Use the public GitHub repository for homepage and support:

- **Homepage:** `https://github.com/iurysza/tab-declutter`
- **Support:** `https://github.com/iurysza/tab-declutter/issues`

### Store Listing fields

- **Title:** Tab Declutter
- **Summary (short description):** AI tab groups for Chrome, with your own API key. Pick a lens, group in one click, undo in one click.
- **Category:** Productivity
- **Language:** English
- **Privacy policy:** `https://github.com/iurysza/tab-declutter/blob/main/docs/privacy.md`

### Detailed description

> A crowded Chrome window hides the tabs you need. Tab groups only help when someone names and maintains them.
>
> Tab Declutter sorts the tabs in your current window into named tab groups, using the AI provider and API key you choose. Pick a lens, click once, and undo in one click.
>
> Four lenses decide what belongs together:
> • Project: tabs that serve the same goal, across sites.
> • Topic: tabs about the same subject.
> • Session: tabs you opened or used around the same time.
> • Next step: what you still need to do. Act now, Read later, Reference, or Probably done.
> You can also write your own lens.
>
> Press Alt+Shift+G to group with your last-used lens without opening the popup. The toolbar badge shows the result.
>
> Pinned and split-view tabs stay where they are. Tabs that don't clearly fit stay ungrouped. Undo restores the previous order, groups, names, colors, and collapsed state.
>
> Works with OpenAI, Anthropic, Google, and OpenAI-compatible services.
>
> Privacy: Tab Declutter has no account, server, analytics, or telemetry. Requests go straight from your browser to your provider. It sends tab titles and trimmed URLs, never page contents, history, bookmarks, or cookies. The Session lens also sends a rounded "last used" time and which tab opened each tab. Your API key stays in this Chrome profile.
>
> Report problems at https://github.com/iurysza/tab-declutter/issues

Avoid keyword lists, repeated terms, or claims that are not visible in the product.

## 5. Complete Privacy practices

### Single purpose

> Organize tabs in the active Chrome window into named groups using a user-configured AI provider, with one-step Undo.

### Permission justifications

**`tabs`**

> Reads tab IDs, titles, URLs, positions, pinned state, split-view state, last-used time, and opener tab in the active window so Tab Declutter can classify eligible tabs, create groups, and restore the previous layout. Tab Declutter does not read page contents.

**`tabGroups`**

> Creates and names Chrome tab groups, reads existing group metadata, and restores group title, color, collapsed state, and membership during Undo.

**`storage`**

> Stores provider settings and custom criteria in profile-local storage. Stores one pending or ready Undo snapshot in session storage so recovery survives service-worker suspension.

**`optional_host_permissions`** (`https://*/*`, `http://localhost/*`, `http://127.0.0.1/*`, `http://[::1]/*`)

> Tab Declutter connects directly to the AI provider you choose, using your own key. Because OpenAI-compatible providers can be any HTTPS origin, the manifest declares a broad HTTPS optional host permission; at runtime Tab Declutter requests access only to the exact origin shown in **Save settings**, and only when you press that button. Native OpenAI, Anthropic, and Google providers use their fixed origins. HTTP is limited to `localhost`, `127.0.0.1`, and `[::1]` for development.

### Remote code

Select **No, I am not using remote code**. Provider responses are treated as untrusted data and validated against a bundled schema. All executable JavaScript ships in the extension package.

### Data disclosure

Disclose at least:

- **Web history:** eligible tab titles and trimmed URLs are sent directly to the AI provider you selected so it can suggest groups. With the Session lens, a rounded last-used time and the opener tab's temporary reference are also sent.
- **Authentication information:** your provider API key is stored in `chrome.storage.local` and is sent only to authenticate requests to that provider.
- **User-provided content:** custom lens names and instructions are sent as part of the grouping request.

Certify that data is used only for Tab Declutter's single purpose and is not sold, used for advertising, or transferred for unrelated purposes. The public privacy policy and in-product copy name the user-selected AI provider as the receiving third party.

## 6. Reviewer access

Tab Declutter needs a working provider to demonstrate grouping. In the dashboard's **Test instructions** tab, provide a temporary, budget-limited API key and exact model ID. Keep it only in the dashboard, never in the repository. Revoke it after review.

Reviewer flow:

1. Open Tab Declutter **Settings** from the popup.
2. Choose the supplied provider and enter the model ID from the Test instructions.
3. Paste the temporary API key, select **Save settings**, and allow the provider origin.
4. Open at least three ordinary tabs in the current window.
5. Open the popup, choose **Project**, and select **Group N tabs**.
6. Confirm named groups appear in the active window.
7. Select **Undo** and confirm the original order and groups return.
8. Press Alt+Shift+G and confirm the badge shows the number of groups made.

## 7. Upload an update

1. In the Developer Dashboard, open Tab Declutter and go to **Package**.
2. Upload `tab-declutter-v0.2.0.zip` from the release.
3. Update **Store Listing** with the summary, description, and screenshots above.
4. Update **Privacy** with the Session lens data disclosure above.
5. Select **Submit for Review**.

Reviews usually take a few days, but can take weeks.

## 8. Automate later updates

The [Chrome Web Store API](https://developer.chrome.com/docs/webstore/using-api) can upload and publish new versions. It needs a Google Cloud project with the API enabled, OAuth credentials with the `https://www.googleapis.com/auth/chromewebstore` scope, and the publisher and extension IDs. Store the credentials only in CI secrets.
